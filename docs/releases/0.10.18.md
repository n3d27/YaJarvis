# YaJarvis 0.10.18

- Колонка с первого раза слышит фразу, сказанную сразу после «Джарвис». Пока подключается ChatGPT, начало фразы копится в очереди. Раньше эту очередь догоняли ускорением речи в 1,5–1,9 раза, и модель не разбирала слова. Теперь выкидываются только паузы, а речь доходит как есть.
- Убрано самописное подавление эха после отклика «Да?». Эхо собственного голоса уже вычитает штатная обработка звука Станции (Yandex VQE), и повторное вычитание только портило начало фразы.
- ChatGPT: звонок надёжнее открывается, а фраза, отправленная сразу после подключения, больше не теряется.
- Память: при обновлении досье не пропадают факты, о которых модель не упомянула. «Запомни» дописывает сразу, а «забудь» удаляет только подходящие факты.
- Команды Алисе отправляются, когда фраза договорена до конца, а не на полуслове. «Стоп» по-прежнему срабатывает сразу.
- YouTube (плагин `youtube` 1.1.1): на «включи плейлист» без названия Джарвис переспросит, какой включить. Имя аккаунта Google теперь подтягивается точнее.
- VPN (плагин `vpn` 0.3.5): меньше потерь UDP-пакетов через VPN.
- Панель: обновлён раздел «Обновления».
